# Changelog

All notable changes to Monokai Neon are documented in this file.

The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses a Release Please workflow to prepare version bumps and changelog entries from merged commits.

## [Unreleased]

## [0.1.0] - 2026-03-21

### Added
- Rebuilt the theme from a source-first workflow that generates committed theme JSON files and README preview assets.
- Added four maintained theme variants: the default Monokai Neon palette, a higher-contrast build, a cooler Storm build, and a pure-black OLED build.
- Added semantic-token-aware, language-specific theming for TypeScript, Python, Go, Rust, Markdown, JSON, HTML, CSS, shell, and diff scopes.
- Added CI validation and publishing workflows for Release Please, Open VSX, npm, and packaged VSIX artifacts.
- Expanded the README with accessibility notes, release instructions, publishing requirements, and multiple syntax/interface previews.
